# BSUIR Schedule Bot

Telegram-бот для автоматического расписания БГУИР.

## Возможности

- **Автоматические уведомления** — начало пары, перемена, предупреждения за 3 мин
- **Информация о паре** — предмет, преподаватель, аудитория, корпус, подгруппа
- **Фильтрация по подгруппам** — каждая подгруппа получает своё расписание
- **Двуязычный интерфейс** — русский и английский с мгновенным переключением
- **Просмотр расписания** — сегодня, завтра, неделя
- **Текущая и следующая пара** — с обратным отсчётом
- **Поиск группы** — по названию факультета или номеру
- **Уведомление об окончании дня** — когда последняя пара закончилась

## Стек

Node.js · bsuir-iis-api · node-telegram-bot-api · node-cron
